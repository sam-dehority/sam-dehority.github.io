### Basic info

This page mostly collects SageMath notebooks for the Spring 2021 SHP course Chaos and Fractals. There is also a [github page](https://github.com/sam-dehority/SHPChaoasandFractals2021Spring) where there are (temporary) links to the CoCalc pages for the demos and problem notebooks for a given week. The main github page lists these links, and below there are links to the github files for each week.  

Generally, until a few days after a lecture the problems sheet will not have solutions, but after the lecture solutions will be posted in the problems file.
