Software
------

The following SageMath code and associated Jupyter notebooks were mostly not designed for 
public use and come with no guarantee of correctness. Nevertheless they may prove useful to somebody. 

- [Vertex algebras](https://github.com/sam-dehority/VertexAlgebrasinSage) contains code and notebooks allowing for the calculation of OPEs in vertex (super)algebras. It is even clever enough to handle terms from the non-singular part of OPEs which are useful for a number of applications. 

- [Lie algebra methods](https://github.com/sam-dehority/kac-moody-voas-and-heisenberg) contains methods for even lattice vertex operator algebras
and Kac-Moody algebras. E.g. one may find a basis for a given root space of a Kac-Moody algebra in terms of Chevalley generators.

- [Quiver methods](https://github.com/sam-dehority/quivers) contains methods for doing calculations with quiver varieties and quiver representations. E.g. computing the stratifications of quiver varieties for non-generic stability parameter. 

- [n-dimensional partitions](https://github.com/sam-dehority/ndpartitions) allows one to do some computations with n-dimensional partitions extending the plane partition calculations already available in sage.
